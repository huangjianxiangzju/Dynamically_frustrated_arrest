# Manuscript-numbered figures

This directory contains the eight main and 18 supplementary PNGs aligned with the manuscript after Materials and Methods was moved before Results. `FIGURE_INDEX.csv` identifies every figure and filename; `FIGURE_CAPTIONS.md` supplies the supplementary captions from the corresponding SI. `SUPPLEMENTARY_NUMBERING_MAP.csv` maps the previous figures, tables and notes to the current numbers. Main figure numbers and supplementary table numbers are unchanged.

`Supplementary_figures/Supplementary_Figure_14.png` is the approved corrected integrated-ranking figure (previously S13), not the elbow plot now numbered S13. Its vector PDF and 600-dpi TIFF are included alongside the PNG. The deposited script and ranking tables reproduce its numerical content.

Other images are unchanged exports from the renumbered submission package. `resolution_manifest.csv` records their pixel dimensions, effective resolution at manuscript display size, and hashes. These are not all native 600-dpi renderings: color images meet the 300-dpi minimum at the documented sizes. Historical descriptive figure directories remain in the repository; use this index for current manuscript numbering.
